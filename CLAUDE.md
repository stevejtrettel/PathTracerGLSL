# CLAUDE.md

WebGL2 **research path tracer** — no frameworks, pure WebGL2/GLSL 300 es, TypeScript strict, Vite. The owner is a mathematician; long-term goals include volumetric media, swappable material/transport models, complex multi-material objects, and eventually non-Euclidean spaces (H³, Nil, black-hole metrics). Read this file, then trust the `docs/fable-*.md` documents as design authority.

npm run dev          # dev server on port 3000 (root = suite GALLERY; click a card → lab.html?scene=<id> renders it; witness registry tests/witnesses/, demos demos/, merged view pages/registry.ts)

## Architecture (four layers, dependency direction App → Engine → Compiler → Components)

- **App** (`src/app/`) — facade + managers (RendererManager, RenderCoordinator, ProductionOrchestrator, ParameterStore, EventBus) + extensions + UI library.
- **Engine** (`src/engine/`) — executes `CompiledRenderer` objects **blindly**. It must never know about scenes, materials, or algorithms. Do not leak compiler/scene concepts into the engine — this boundary is load-bearing.
- **Compiler** (`src/compiler/`) — Analyze → Validate → Plan → Generate. Turns `SceneDescription + RenderStrategy` into `CompiledRenderer` (shaders + pipeline + uniform bindings). Assembly goes through `ShaderIR.ts` blocks so source maps track provenance. Pure TS — the compiler contains **zero** `.glsl` files (July 2026 layout reorg).
- **Fixed GLSL** (`src/glsl/`) — the non-swappable GLSL layer: `core/` is the contract spine + stdlib every component is written against (structs, interaction, math, ray — the leaf-visible vocabulary); `shared/` is compiler-pass plumbing components never see (fullscreen.vert, display safe_color/OETF, blue-noise accessor). Every `.glsl` in the repo is either `components/` (swappable, behind a registry) or `glsl/` (fixed) — nowhere else.
- **Components** (`src/components/`) — the LEAF library of swappable research code (`docs/fable-components.md`): materials, lights, volume_scattering (the phase functions), geometry, ambient, intersection, accel (the spatial-index substrate: BVH build core + ray-walk support — build shared, queries live with their domains), transport (incl. the pt loop generator), env, sampler, pixel, camera, sensor, accumulator, tonemap — GLSL occupants (Vite `?raw`) + descriptors + per-family registries (intersection's — held since founding — opened Jul 20 2026 with the traversal axes `MESH_TRAVERSALS`/`INSTANCE_ACCELS`; geometry BACKENDS deliberately have no registry — they are scene-derived capabilities that compose). **RAIL v2** (`components/data/` — the second substrate family; authority `docs/fable-data-rail.md`, owner-approved Jul 20 2026): ALL scene-scale array data rides SIX shared channels (`data_vertices/normals/uvs/indices/nodes/records`) — tenants are regions with LEDGER-baked base offsets (`planDataLayout` = the one layout truth, fed by `compiler/plan/dataTenants.ts` on both Planner and App sides; BVH regions padded to the 2T−1 bound). Texture count is role-shaped, never tenant-shaped; the Generator enforces the 16-unit spec floor with an itemized compile error (`samplerBudget.test.ts` pins cacti/forest ≤ 13). `data_indices.w` is reserved as the per-triangle material-group slot; Stage B tables/light-BVH/majorant grids land in `records`/`nodes`. Components import NOTHING from app/engine/compiler except contract types (`import type` only — enforced by `tests/components/purity.test.ts`); everyone imports from components. **1 component = 1 folder** (`{name.glsl, name.ts, name.md?, tests}` — the md is the occupant's math, optional/post-hoc-fillable); every family root has a `README.md` contract doc (taxonomy section, kind, occupant contract, recipe) — both enforced by `tests/components/structure.test.ts`. Adding an occupant = one folder + one registry line.

## Critical conventions

- **Naming (July 17 2026):** GLSL occupant symbols are TYPE-FIRST (`<occupant>_<op>`: `sphere_sdf`, `lambert_eval`, `quad_light_sample` — lights keep the `_light_` infix). Material/light/region ids are INSERTION-ORDER (names are provenance; renaming is artifact-free; integer-like material names rejected). Parameter prefixes `engine./env./debug./renderer.` + `camera.position/target/frame` are RESERVED (compiler/types.ts, Validator-enforced); `camera.fov` is authored convention. Authored object `name`s become emitted symbols (`sdf_<name>`, `shape_<name>`).
- **Input language (July 17 2026):** objects are SHAPE-not-backend (`{ type, parameters, ... , backend? }` — the pin is research/coverage annotation); lights and materials author radiometrics as ONE word, `emission`; the authored material record is OPEN (legal keys = the model's schema rows).
- **Shader ID namespacing:** the Engine stores programs in a flat map — shader IDs MUST be prefixed with the renderer ID (`${rendererId}-main`), and renderer IDs are `${strategy.id}-${scene.id}`. Collisions silently clobber programs.
- **Uniforms:** `u_camelCase` in GLSL; `dotted.path` parameter names in TS. Engine builtins injected each frame: `engine.resolution`, `engine.sampleCount`, `engine.resetSalt`, `engine.time`, `engine.pixelOffset`, `engine.imageSize` (`engine.frameIndex` was DROPPED — §2.11).
- **Spectral discipline** (contracts §2.5): in library/template GLSL, never write raw `vec3(...)` literals for radiometric quantities; reductions via `spectrum_*` helpers; radiometric constants are emitted by the Generator's formatter.
- **GLSL types:** `Point`, `Direction`, `Spectrum`, `Radiance` are typedefs (currently `vec3`; `Point` may become `vec4` for curved spaces). Write against the typedefs.
- **HDR export reads `accumulation_previous`** — post-frame swap semantics; see the comment in `PipelineBuilder.ts` before "correcting" it.
- **Model-authored design docs** are prefixed by author (`fable-…`) so provenance is visible. Follow the pattern for substantial new design docs.
- Fullscreen triangle via `gl_VertexID` (no VAO). Buffer qualifiers `_current`/`_previous` are reserved suffixes on framebuffer IDs.

## Verifying changes

- `npx vitest run` covers compiler structure (shader assembly, source maps, validation) + glslang static compile of every registry pair. It does NOT execute GLSL — runtime behavior needs the browser or the witness runner.
- **`npm run witness`** — the numeric gate: headless-renders the `tests/witnesses/` registry and asserts the derived numbers (furnace 0.4, F-ETA 0.5540, slab, convergence equalities, equal-spp noise). Minutes-long, deliberately NOT in vitest. Run it after any change to sampling/lighting/transport GLSL; `npm run witness -- <scene…>` filters, `--list` enumerates. Don't run two instances concurrently (SwiftShader contention → timeouts). Adding a witness = one fixture in `witnesses/scenes/` + one registry entry (gate policy: `witnesses/README.md`).
