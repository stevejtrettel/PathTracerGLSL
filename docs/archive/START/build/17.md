# Phase 17: Extension System

## Goals and Purpose

Phase 17 introduces the extension system that enables unlimited feature growth without modifying the core application. We're solving a fundamental architectural problem: research tools need diverse capabilities - keyboard shortcuts, UI panels, experiment automation, data export - but adding each feature directly to ResearchApp would create an unmaintainable monolith. The extension system provides a plugin architecture where features can be added, removed, and modified independently while the core remains stable.

The critical test here is that extensions can discover and use each other through a service registry, communicate through events without tight coupling, and add significant functionality without touching core code. A keyboard extension can trigger resets, a UI extension can display stats, and they can work together without knowing about each other's implementation. This loose coupling enables a ecosystem of extensions that combine in powerful ways.

## What We're Building

### The Extension Architecture

**Extension Interface** defines the contract all extensions must fulfill. Extensions have a name, declare their dependencies, provide an install method that sets them up, and optionally provide an uninstall method for cleanup. This simple interface is enough to support everything from keyboard handlers to complex experiment automation. The key insight is that extensions register themselves as services rather than modifying the app directly.

**Service Registry Pattern** provides a discovery mechanism where extensions can find and use each other. Instead of the app knowing about specific extensions, extensions register themselves under service names. When a stats panel needs keyboard shortcuts, it asks the registry for the 'keyboard' service. This inversion of control means the app never needs to know what extensions exist.

**EventBus for Communication** enables loose coupling between components through a publish-subscribe pattern. Extensions emit events about their activities and listen for events they care about. The keyboard extension emits 'key.pressed', the camera extension listens for it, but neither knows about the other. This decoupling means extensions can be added or removed without breaking others.

**Standard Extension Examples** demonstrate the patterns. The KeyboardInput extension adds keyboard controls by listening to DOM events and emitting standardized events. The StatsPanel extension creates a UI overlay showing render progress by listening to progress events. These simple examples establish patterns that scale to complex functionality.

### Architectural Patterns Established

This phase establishes several critical patterns:

1. **Services Over Modifications** - Extensions provide services, don't modify app
2. **Discovery Through Registry** - Dynamic service lookup enables composition
3. **Event-Based Integration** - Loose coupling through publish-subscribe
4. **Dependency Declaration** - Extensions declare what they need

### What Changes After Phase 17

Before Phase 17: All functionality built into ResearchApp, monolithic growth.

After Phase 17:
- Features can be added without modifying core
- Extensions can discover and use each other
- Keyboard shortcuts and UI work through extensions
- Foundation for unlimited feature growth
- Core remains small and stable

Being able to press 'r' to reset and see stats update, with both features implemented as extensions that don't know about each other, proves the extension system enables powerful composition through loose coupling.

### EventBus Implementation

```typescript
class EventBus {
  private listeners = new Map<string, Set<EventHandler>>();
  private eventLog: EventLogEntry[] = [];  // For debugging
  
  on(event: string, handler: EventHandler): void {
    // Subscribe to events
    
    if (!this.listeners.has(event)) {
      this.listeners.set(event, new Set());
    }
    
    this.listeners.get(event)!.add(handler);
  }
  
  off(event: string, handler: EventHandler): void {
    // Unsubscribe from events
    
    this.listeners.get(event)?.delete(handler);
  }
  
  once(event: string, handler: EventHandler): void {
    // Subscribe for single event
    
    const wrapper = (data: any) => {
      handler(data);
      this.off(event, wrapper);
    };
    
    this.on(event, wrapper);
  }
  
  emit(event: string, data?: any): void {
    // Publish event to all listeners
    
    // Log for debugging
    if (this.eventLog.length > 1000) {
      this.eventLog.shift();  // Circular buffer
    }
    this.eventLog.push({ event, data, timestamp: performance.now() });
    
    // Notify all handlers
    const handlers = this.listeners.get(event);
    if (!handlers) return;
    
    // Copy to prevent modification during iteration
    const handlersCopy = Array.from(handlers);
    
    for (const handler of handlersCopy) {
      try {
        handler(data);
      } catch (error) {
        console.error(`Error in event handler for ${event}:`, error);
        // Don't let one bad handler break others
      }
    }
  }
  
  // Debugging helpers
  getEventLog(): EventLogEntry[] {
    return this.eventLog.slice();
  }
  
  getListenerCount(event?: string): number {
    if (event) {
      return this.listeners.get(event)?.size || 0;
    }
    
    let total = 0;
    for (const handlers of this.listeners.values()) {
      total += handlers.size;
    }
    return total;
  }
}
```

EventBus provides robust publish-subscribe with error isolation and debugging support.

### ServiceRegistry Implementation

```typescript
class ServiceRegistry {
  private services = new Map<string, any>();
  private bus: EventBus;
  
  constructor(bus: EventBus) {
    this.bus = bus;
  }
  
  register(name: string, service: any): void {
    // Register a service for discovery
    
    if (this.services.has(name)) {
      console.warn(`Service '${name}' already registered, replacing`);
    }
    
    this.services.set(name, service);
    
    // Emit event for service watchers
    this.bus.emit('service.registered', { name, service });
  }
  
  unregister(name: string): void {
    // Remove a service
    
    if (this.services.delete(name)) {
      this.bus.emit('service.unregistered', { name });
    }
  }
  
  get<T = any>(name: string): T | undefined {
    // Retrieve a service by name
    return this.services.get(name);
  }
  
  require<T = any>(name: string): T {
    // Retrieve service or throw if missing
    
    const service = this.get<T>(name);
    if (!service) {
      throw new Error(`Required service '${name}' not found`);
    }
    return service;
  }
  
  has(name: string): boolean {
    // Check if service exists
    return this.services.has(name);
  }
  
  list(): string[] {
    // List all registered services
    return Array.from(this.services.keys());
  }
}
```

ServiceRegistry enables dynamic discovery of functionality.

### ResearchApp Extension Support

```typescript
class ResearchApp {
  // Core systems
  public engine: Engine;
  public parameterStore: ParameterStore;
  public renderCoordinator: RenderCoordinator;
  public recipeManager: RecipeManager;
  
  // Extension system
  private extensions = new Map<string, Extension>();
  private serviceRegistry: ServiceRegistry;
  private eventBus: EventBus;
  
  constructor(canvas: HTMLCanvasElement, bundle: RecipeBundle) {
    // Initialize core as before...
    
    // Create extension system
    this.eventBus = new EventBus();
    this.serviceRegistry = new ServiceRegistry(this.eventBus);
    
    // Register core services
    this.serviceRegistry.register('app', this);
    this.serviceRegistry.register('engine', this.engine);
    this.serviceRegistry.register('parameters', this.parameterStore);
    this.serviceRegistry.register('coordinator', this.renderCoordinator);
  }
  
  use(extension: Extension): ResearchApp {
    // Install an extension
    
    // Check dependencies
    for (const dep of extension.dependencies || []) {
      if (!this.extensions.has(dep)) {
        throw new Error(
          `Extension '${extension.name}' requires '${dep}' to be installed first`
        );
      }
    }
    
    // Install extension
    console.log(`Installing extension: ${extension.name}`);
    
    try {
      extension.install(this, this.eventBus);
      this.extensions.set(extension.name, extension);
      
      // Emit installation event
      this.eventBus.emit('extension.installed', {
        name: extension.name,
        extension
      });
      
    } catch (error) {
      console.error(`Failed to install extension '${extension.name}':`, error);
      throw error;
    }
    
    return this;  // For chaining
  }
  
  getService<T = any>(name: string): T | undefined {
    // Public service access
    return this.serviceRegistry.get<T>(name);
  }
  
  registerService(name: string, service: any): void {
    // Extensions can register services
    this.serviceRegistry.register(name, service);
  }
}
```

ResearchApp provides the infrastructure for extensions to integrate.

### KeyboardInput Extension

```typescript
class KeyboardInputExtension implements Extension {
  name = 'keyboard';
  description = 'Keyboard controls for common operations';
  
  private keyBindings = new Map<string, () => void>();
  private enabled = true;
  
  install(app: ResearchApp, bus: EventBus): void {
    // Register as keyboard service
    app.registerService('keyboard', this);
    
    // Set up default key bindings
    this.bindKey('r', () => {
      // Reset accumulation
      console.log('Reset triggered by keyboard');
      app.renderCoordinator.resetAccumulation();
      bus.emit('keyboard.reset');
    });
    
    this.bindKey(' ', () => {
      // Toggle pause/resume
      if (app.renderCoordinator.isRunning()) {
        app.renderCoordinator.stop();
        bus.emit('keyboard.pause');
      } else {
        app.renderCoordinator.start();
        bus.emit('keyboard.resume');
      }
    });
    
    this.bindKey('m', () => {
      // Cycle render modes
      const modes: RenderMode[] = ['interactive', 'progressive', 'production'];
      const current = app.renderCoordinator.getMode();
      const next = modes[(modes.indexOf(current) + 1) % modes.length];
      
      app.renderCoordinator.setMode(next);
      bus.emit('keyboard.modeChange', { mode: next });
    });
    
    // Listen to DOM events
    document.addEventListener('keydown', this.handleKeyDown);
  }
  
  private handleKeyDown = (event: KeyboardEvent): void => {
    // Process keyboard events
    
    if (!this.enabled) return;
    
    // Ignore if typing in input field
    if (event.target instanceof HTMLInputElement) return;
    
    const handler = this.keyBindings.get(event.key);
    if (handler) {
      event.preventDefault();
      handler();
    }
  };
  
  bindKey(key: string, handler: () => void): void {
    // Public API for other extensions to add bindings
    this.keyBindings.set(key, handler);
  }
  
  unbindKey(key: string): void {
    this.keyBindings.delete(key);
  }
  
  uninstall(): void {
    // Clean up
    document.removeEventListener('keydown', this.handleKeyDown);
  }
}
```

KeyboardInput provides keyboard controls through the extension system.

### StatsPanel Extension

```typescript
class StatsPanelExtension implements Extension {
  name = 'stats';
  description = 'Overlay showing rendering statistics';
  dependencies = ['keyboard'];  // Uses keyboard for toggle
  
  private panel: HTMLDivElement;
  private visible = true;
  private stats = {
    samples: 0,
    fps: 0,
    renderTime: 0,
    mode: 'progressive' as RenderMode
  };
  
  install(app: ResearchApp, bus: EventBus): void {
    // Create UI panel
    this.createPanel();
    
    // Register as service
    app.registerService('stats', this);
    
    // Listen to render progress
    bus.on('render.progress', (info: ProgressInfo) => {
      this.updateStats(info);
    });
    
    // Listen to mode changes
    bus.on('coordinator.modeChanged', (data) => {
      this.stats.mode = data.mode;
      this.updateDisplay();
    });
    
    // Add keyboard toggle (using keyboard service)
    const keyboard = app.getService<KeyboardInputExtension>('keyboard');
    keyboard?.bindKey('s', () => {
      this.toggle();
      bus.emit('stats.toggled', { visible: this.visible });
    });
  }
  
  private createPanel(): void {
    // Build DOM elements for stats display
    
    this.panel = document.createElement('div');
    this.panel.id = 'stats-panel';
    this.panel.style.cssText = `
      position: fixed;
      top: 10px;
      right: 10px;
      background: rgba(0, 0, 0, 0.7);
      color: white;
      padding: 10px;
      font-family: monospace;
      font-size: 12px;
      z-index: 1000;
      min-width: 200px;
    `;
    
    document.body.appendChild(this.panel);
    this.updateDisplay();
  }
  
  private updateStats(info: ProgressInfo): void {
    // Update statistics from progress events
    
    if (info.samples !== undefined) {
      this.stats.samples = info.samples;
    }
    
    if (info.fps !== undefined) {
      this.stats.fps = info.fps;
    }
    
    if (info.frameTime !== undefined) {
      this.stats.renderTime = info.frameTime;
    }
    
    this.updateDisplay();
  }
  
  private updateDisplay(): void {
    // Update panel content
    
    if (!this.panel) return;
    
    this.panel.innerHTML = `
      <div>Mode: ${this.stats.mode}</div>
      <div>Samples: ${this.stats.samples}</div>
      <div>FPS: ${this.stats.fps.toFixed(1)}</div>
      <div>Frame: ${this.stats.renderTime.toFixed(2)}ms</div>
      <hr style="border-color: #444">
      <div style="color: #888">
        [R] Reset | [Space] Pause<br>
        [M] Mode | [S] Stats
      </div>
    `;
  }
  
  toggle(): void {
    this.visible = !this.visible;
    this.panel.style.display = this.visible ? 'block' : 'none';
  }
  
  uninstall(): void {
    // Clean up DOM
    this.panel?.remove();
  }
}
```
