# Phase 9: Path Tracing WITHOUT NEE

## Goals and Purpose

Phase 9 transforms our renderer from computing only direct illumination to simulating full global illumination through recursive light bouncing. We're implementing path tracing - following light paths that bounce multiple times between surfaces, capturing the subtle interplay of indirect light that makes scenes appear realistic. Light bouncing off a white wall illuminates nearby objects; colored surfaces tint their neighbors; occluded areas receive soft illumination from the environment.

The critical test here is managing recursive light transport: maintaining path throughput correctly as light bounces between surfaces, sampling new directions according to surface properties, and terminating paths intelligently to avoid infinite recursion. We're deliberately NOT implementing Next Event Estimation yet, which means our only way to find lights is by randomly hitting them. This creates substantial noise but proves our recursive transport works before adding optimizations.

## What We're Building

### The Path Tracing System

**Recursive Bouncing** follows light paths through multiple surface interactions. At each surface, we sample a new direction according to the material's properties and continue tracing. Each bounce multiplies the path's throughput by the surface reflectance and geometric factors, accumulating the total light contribution along the entire path. This recursive process captures all the subtle light interactions that create realistic imagery.

**Material Emission** transforms objects into light sources. Any material can emit light by having non-zero emission values. Unlike the point light from Phase 6, emissive materials are area sources discovered only when rays happen to hit them. Without NEE to explicitly sample these lights, finding them relies on chance, which is why the image will be very noisy.

**Direction Sampling** through `interaction_surface_scatter()` implements importance sampling for material BRDFs. For our Lambert surfaces, this means cosine-weighted hemisphere sampling - directions near the normal are more likely than grazing angles. This importance sampling reduces variance by sending rays where they're most likely to contribute significantly.

**Russian Roulette** provides unbiased path termination. After a few bounces, we randomly terminate paths with probability based on their throughput. If a path survives, we boost its contribution to maintain the correct expected value. This elegant technique prevents infinite recursion while keeping the algorithm mathematically unbiased.

### Architectural Patterns Established

This phase establishes several critical patterns:

1. **Throughput Tracking** - Accumulated path contribution weight
2. **Recursive Transport** - Paths bounce until termination
3. **Importance Sampling** - Directions chosen based on BRDF shape
4. **Unbiased Termination** - Russian roulette maintains correctness

### What Changes After Phase 9

Before Phase 9: Only direct lighting - surfaces are black if not directly lit.

After Phase 9:
- Indirect illumination appears everywhere
- Color bleeding between surfaces becomes visible
- Shadows are no longer completely black
- The image is VERY noisy (no direct light sampling)

The noisy but globally illuminated scene proves our path tracer correctly simulates recursive light transport even without optimizations.

## Implementation Sketch

### Extended Transport with Path Tracing

```typescript
const pathTracingTransport: ModuleDescriptor = {
  id: { kind: 'transport', name: 'pathtracer', version: '1.0.0' },
  
  fragment: {
    constants: `
      #define MAX_BOUNCES 10
      #define RR_START_DEPTH 3    // Start Russian roulette after 3 bounces
    `,
    
    functions: `
      vec3 transport_trace(Ray ray) {
        // Accumulate radiance along a path
        vec3 throughput = vec3(1.0);  // Path contribution weight
        vec3 radiance = vec3(0.0);     // Accumulated light
        
        for (int bounce = 0; bounce < MAX_BOUNCES; bounce++) {
          Hit hit;
          if (!scene_intersect(ray, hit)) {
            // Ray escaped to environment
            // In a real system, add environment light here
            break;
          }
          
          // Build frame for shading calculations
          hit.frame = geometry_frame(hit.p, hit.n);
          
          // Get material properties
          MaterialProperties props = scene_material_properties(
            hit.material_to, hit.p
          );
          
          // Add emission from surface we just hit
          // This is how we "find" light sources randomly
          if (length(props.emission) > 0.0) {
            radiance += throughput * props.emission;
          }
          
          // Russian roulette termination
          if (bounce >= RR_START_DEPTH) {
            float p_survive = min(1.0, luminance(throughput));
            if (next_1d() > p_survive) {
              break;  // Terminate path
            }
            throughput /= p_survive;  // Boost surviving paths
          }
          
          // Sample next direction
          float pdf;
          vec3 wi = interaction_surface_scatter(
            -ray.direction,  // Incoming direction
            hit,
            next_2d(),
            pdf
          );
          
          if (pdf <= 0.0) {
            break;  // No valid scattering direction
          }
          
          // Evaluate BRDF
          vec3 f = interaction_surface_shade(
            wi,              // Toward next bounce
            -ray.direction,  // From previous bounce
            hit
          );
          
          // Update throughput
          float cos_theta = abs(dot(wi, hit.n));
          throughput *= f * cos_theta / pdf;
          
          // Set up next ray
          ray.origin = hit.p + hit.n * EPSILON;
          ray.direction = wi;
        }
        
        return radiance;
      }
    `
  }
};
```

The path tracing loop accumulates light contributions along a path, maintaining the throughput (accumulated reflectance and geometric terms) that weights each emission contribution. Russian roulette provides unbiased termination - the survival probability boost ensures the expected value remains correct.

### Direction Sampling in Interaction

```typescript
const lambertInteraction: ModuleDescriptor = {
  id: { kind: 'interaction', name: 'lambert', version: '1.0.0' },
  
  fragment: {
    functions: `
      vec3 interaction_surface_scatter(vec3 wo, Hit hit, vec2 xi, out float pdf) {
        // Sample new direction for Lambert diffuse
        // Cosine-weighted hemisphere sampling
        
        // Generate cosine-distributed direction
        float cos_theta = sqrt(xi.y);  // Cosine weighting
        float sin_theta = sqrt(1.0 - xi.y);
        float phi = 2.0 * PI * xi.x;
        
        // Build direction in local frame
        vec3 local_wi = vec3(
          sin_theta * cos(phi),
          sin_theta * sin(phi),
          cos_theta
        );
        
        // Transform to world space using hit frame
        vec3 wi = hit.frame.t * local_wi.x +
                  hit.frame.b * local_wi.y +
                  hit.frame.n * local_wi.z;
        
        // PDF for cosine-weighted hemisphere sampling
        pdf = cos_theta / PI;
        
        return wi;
      }
      
      vec3 interaction_surface_emit(Hit hit) {
        // Query emission from material
        MaterialProperties props = scene_material_properties(
          hit.material_to, hit.p
        );
        return props.emission;
      }
    `
  }
};
```

Cosine-weighted sampling generates directions proportional to the cosine term in the rendering equation, reducing variance by sending more rays in directions that contribute more to the final result. The PDF must match the sampling distribution for the Monte Carlo estimator to be unbiased.

### Material Emission

```glsl
struct MaterialProperties {
  vec3 albedo;
  vec3 emission;  // Light emission (radiance for area lights)
}

// In Scene module
MaterialProperties scene_material_properties(int mat_id, Point p) {
  MaterialProperties props;
  
  if (mat_id == SPHERE_MATERIAL) {
    props.albedo = vec3(0.8, 0.8, 0.8);
    props.emission = vec3(0.0);  // Not emissive
  } else if (mat_id == LIGHT_MATERIAL) {
    props.albedo = vec3(0.0);
    props.emission = vec3(10.0, 10.0, 10.0);  // Bright white light
  }
  
  return props;
}
```

Any material can emit light, turning geometry into area light sources. Without NEE, these lights are only discovered when paths randomly hit them, making convergence very slow.

### Russian Roulette Mathematics

```glsl
// Russian roulette maintains unbiased results while terminating paths
// 
// Expected value without RR:
// E[L] = throughput * future_contribution
//
// With RR (probability p of continuing):
// E[L] = p * (throughput/p) * future_contribution + (1-p) * 0
//      = throughput * future_contribution
//
// The same expected value! The 1/p boost compensates for terminated paths.

float p_survive = min(1.0, luminance(throughput));
// - Use throughput luminance as survival probability
// - Darker paths more likely to terminate
// - Clamp to 1.0 to avoid boosting bright paths

if (next_1d() > p_survive) {
  break;  // Terminate with probability (1 - p_survive)
}
throughput /= p_survive;  // Boost survivors to maintain expected value
```
