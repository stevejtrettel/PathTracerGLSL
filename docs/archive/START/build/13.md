# Phase 13: NEE with MIS

## Goals and Purpose

Phase 13 implements the crown jewel of modern path tracing - Next Event Estimation with Multiple Importance Sampling. We're solving a fundamental problem: pure path tracing (Phase 9) finds lights only by chance, creating enormous variance, while direct light sampling (Phase 6) misses indirect illumination entirely. NEE combines both strategies, explicitly sampling lights at every bounce while also following BSDF-sampled paths, with MIS optimally weighting the contributions to minimize variance.

The critical test here is that our material→light reference system from Phase 12 enables clean MIS implementation. When a path happens to hit an emissive surface, Transport needs to know whether that light could have been sampled directly. The material's `light_id` tells us exactly which light we hit, and `lighting_can_sample()` tells us whether direct sampling was possible. This information enables proper MIS weights without complex object tracking or cross-referencing.

## What We're Building

### The NEE+MIS System

**Next Event Estimation** explicitly samples lights at every path vertex, dramatically reducing variance for direct illumination. At each surface bounce, we sample both a light direction (for direct illumination) and a BSDF direction (for the next bounce). The light sample gives us immediate illumination with known probability, while the BSDF sample continues the path for indirect effects. This "next event" estimation transforms convergence from hours to seconds for many scenes.

**Multiple Importance Sampling** combines the two sampling strategies - light sampling and BSDF sampling - using optimal weights that minimize variance. The power heuristic `weight = (pdf_a²) / (pdf_a² + pdf_b²)` balances contributions based on how well each sampling strategy matches the integrand. When a technique generates a sample in a region where it has high PDF, it gets high weight; where it has low PDF, it gets low weight.

**Complete Hit Structure** now includes `material_from` and `material_to`, enabling proper interface handling for glass and nested dielectrics. The complete structure tracks everything needed for sophisticated transport: position, normal, texture coordinates, frame, and materials on both sides of the interface. This rich information enables correct Fresnel calculations and proper light transport through complex material boundaries.

**Samplability Checking** through `lighting_can_sample()` is crucial for MIS. When we hit an emissive surface through BSDF sampling, we need to know if we could have found it through light sampling instead. Point lights can't be hit randomly (zero probability), while area lights can be found both ways. This distinction determines whether MIS weights are needed.

### Enhanced WorldCompiler Light Registry

```typescript
interface CompiledLight {
  id: string;
  radiance: vec3;
  source: 'explicit' | 'emissive_material';
  
  // NEW: Sampling capability
  canSample: boolean;
  samplingType?: 'point' | 'area' | 'directional' | 'environment';
  
  // Sampling parameters
  position?: vec3;
  area?: number;
  normal?: vec3;
}

class WorldCompiler {
  private analyzeLight(light: LightDescription | MaterialDescription): CompiledLight {
    // Determine if light can be explicitly sampled
    
    if (light.type === 'point') {
      return {
        canSample: true,  // Point lights can be sampled
        samplingType: 'point',
        // Point lights can't be hit randomly (delta distribution)
      };
    }
    
    if (light.source === 'emissive_material') {
      // For now, emissive materials are area lights
      // In future, analyze geometry for sampling capability
      
      const isSimpleGeometry = this.analyzeGeometry(light);
      
      return {
        canSample: isSimpleGeometry,  // Can sample if sphere, quad, etc.
        samplingType: isSimpleGeometry ? 'area' : undefined,
        // Complex geometry can't be sampled efficiently
      };
    }
  }
}
```

The compiler determines sampling capability at compile time, marking which lights can be explicitly sampled versus those only found through path tracing.

### Enhanced Lighting Module

```typescript
// In LightingCompiler
private generateWithSampling(registry: LightRegistry): string {
  return `
    // Light sampling capability array
    const bool light_can_sample[${registry.lights.length}] = bool[](
      ${registry.lights.map(l => l.canSample).join(', ')}
    );
    
    bool lighting_can_sample(int light_id) {
      if (light_id < 0 || light_id >= ${registry.lights.length}) {
        return false;
      }
      return light_can_sample[light_id];
    }
    
    float lighting_pdf(vec3 p, vec3 wi) {
      // Compute PDF of sampling direction wi from point p
      // This is crucial for MIS weight calculation
      
      // For now, assuming one point light
      // Point lights have delta distribution - can't compute PDF
      // Area lights would compute solid angle PDF
      
      return 0.0;  // Delta light - no PDF for random hits
    }
    
    LightSample lighting_sample_nee(vec3 p, vec2 xi) {
      // Sample a light for NEE
      // For Phase 13, sample first samplable light
      
      for (int i = 0; i < ${registry.lights.length}; i++) {
        if (light_can_sample[i]) {
          return sample_light(i, p);
        }
      }
      
      // No samplable lights
      LightSample ls;
      ls.pdf = 0.0;
      return ls;
    }
  `;
}
```

The Lighting module tracks which lights can be sampled and provides PDF evaluation for MIS calculations.

### Transport with NEE+MIS

```glsl
vec3 transport_trace(Ray ray) {
  vec3 throughput = vec3(1.0);
  vec3 radiance = vec3(0.0);
  
  // Track previous PDF for MIS
  float prev_bsdf_pdf = 0.0;
  vec3 prev_position;
  
  for (int bounce = 0; bounce < MAX_BOUNCES; bounce++) {
    Hit hit;
    if (!scene_intersect(ray, hit)) {
      break;
    }
    
    // Complete material interface resolution
    resolve_material_interface(ray, hit);
    
    MaterialProperties props = scene_material_properties(
      hit.material_to, hit.p
    );
    
    // Handle emission with MIS
    if (props.light_id >= 0) {
      if (bounce == 0) {
        // Directly visible - no MIS needed
        radiance += throughput * props.emission;
      } else if (lighting_can_sample(props.light_id)) {
        // This light could have been sampled directly
        // Apply MIS weight to reduce variance
        
        float light_pdf = lighting_pdf(prev_position, ray.direction);
        float mis_weight = power_heuristic(prev_bsdf_pdf, light_pdf);
        radiance += throughput * props.emission * mis_weight;
      } else {
        // Path-only light (can't be sampled)
        // Full contribution, no MIS needed
        radiance += throughput * props.emission;
      }
    }
    
    // NEXT EVENT ESTIMATION
    // Sample direct lighting at this vertex
    LightSample ls = lighting_sample_nee(hit.p, next_2d());
    
    if (ls.pdf > 0.0) {
      // Test visibility
      Ray shadow_ray = make_shadow_ray(hit.p, ls.wi, ls.distance);
      
      if (!scene_intersect_any(shadow_ray, ls.distance)) {
        // Evaluate BSDF for light direction
        vec3 f = interaction_surface_shade(ls.wi, -ray.direction, hit);
        
        // Compute BSDF PDF for this direction
        float bsdf_pdf = interaction_surface_pdf(ls.wi, -ray.direction, hit);
        
        // MIS weight for light sampling
        float mis_weight = power_heuristic(ls.pdf, bsdf_pdf);
        
        // Add direct lighting contribution
        float cos_theta = abs(dot(ls.wi, hit.n));
        radiance += throughput * ls.radiance * f * cos_theta * mis_weight / ls.pdf;
      }
    }
    
    // Sample BSDF for next bounce
    float pdf;
    vec3 wi = interaction_surface_scatter(-ray.direction, hit, next_2d(), pdf);
    
    if (pdf <= 0.0) break;
    
    // Update throughput
    vec3 f = interaction_surface_shade(wi, -ray.direction, hit);
    float cos_theta = abs(dot(wi, hit.n));
    throughput *= f * cos_theta / pdf;
    
    // Russian roulette...
    
    // Set up next ray
    prev_bsdf_pdf = pdf;
    prev_position = hit.p;
    ray = make_ray(hit.p, wi);
  }
  
  return radiance;
}

float power_heuristic(float pdf_a, float pdf_b) {
  // Power heuristic with exponent 2 (proved near-optimal)
  // Prevents one strategy from dominating when its PDF is high
  
  float pdf_a_sq = pdf_a * pdf_a;
  float pdf_b_sq = pdf_b * pdf_b;
  
  return pdf_a_sq / (pdf_a_sq + pdf_b_sq);
}
```

The NEE implementation samples lights at every bounce, evaluates visibility, and combines contributions using MIS weights. The power heuristic ensures smooth blending between sampling strategies.

### Material Interface Resolution

```glsl
void resolve_material_interface(Ray ray, inout Hit hit) {
  // Determine materials on both sides of interface
  
  // Sample points just inside and outside surface
  vec3 p_outside = hit.p + hit.n * EPSILON;
  vec3 p_inside = hit.p - hit.n * EPSILON;
  
  // Query materials at these points
  int mat_outside = scene_material_at(p_outside);
  int mat_inside = scene_material_at(p_inside);
  
  // Determine which is which based on ray direction
  float cos_theta = dot(ray.direction, hit.n);
  
  if (cos_theta < 0.0) {
    // Ray hitting from outside
    hit.material_from = mat_outside;
    hit.material_to = mat_inside;
  } else {
    // Ray hitting from inside (transmission)
    hit.material_from = mat_inside;
    hit.material_to = mat_outside;
    hit.n = -hit.n;  // Flip normal for inside hit
  }
}
```

Complete interface tracking enables proper Fresnel calculations and nested dielectrics.
