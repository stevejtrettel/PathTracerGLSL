# Archived Documentation

These documents are from earlier phases of the project and are preserved for reference.

## What's here

- **START/** — A 20-phase build plan and detailed contracts for a planned system (WorldCompiler, SceneCompiler, ModuleRegistry, etc.) that was superseded by the current Compiler-Engine architecture.

- **PROGRESS/** — Documentation written during the old module/recipe-based system. Includes guides for writing modules, creating recipes, and engine internals from before the refactor.

- **SIMPLE-COMPILER-BUILD-PLAN.md** — The build plan for SimpleCompiler + FlexibleEngine. This was executed successfully (Phases 0-7).

- **BUILD-STRATEGY.md** — The overall two-track build strategy. Phases 0-5 completed. Phase 7 (Real Compiler) not started.
