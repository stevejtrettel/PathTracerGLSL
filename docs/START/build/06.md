# Phase 6: Lambert Direct Lighting (ONE-SHOT)

## Goals and Purpose

Phase 6 introduces illumination - the interplay between light sources and surfaces that creates the perception of depth and form. We're implementing direct lighting, where rays trace straight paths from surfaces to lights, creating the hard shadows and shading gradients that make 3D objects appear solid and situated in space.

The critical test here is the complete direct lighting pipeline: finding light sources, testing visibility with shadow rays, and computing illumination with physically-based cosine falloff. This phase proves our architecture can handle the geometric queries and shading calculations that form the foundation of global illumination, while still maintaining clean separation between light management (Lighting module) and shading behavior (Interaction module).

## What We're Building

### The Direct Lighting System

**Lighting Module** owns knowledge about light sources in the scene. It knows where lights are, how bright they are, and how to sample them. For Phase 6, this is a single point light, but the architecture we're establishing will handle area lights, environment maps, and emissive objects. The Lighting module provides data about lights but doesn't determine how they affect surfaces.

**Shadow Rays** test whether the path from surface to light is clear or blocked. We're adding `scene_intersect_any()` to the Scene module - a specialized intersection routine that just returns true/false for occlusion, without computing hit details. This optimization is crucial for performance since shadow rays only care about blockage, not intersection properties.

**Lambert Shading** implements the simplest physically-plausible reflection model. The amount of light reflected depends on the cosine of the angle between the surface normal and light direction - surfaces facing the light appear bright, grazing angles appear dark, and surfaces facing away receive no direct light. This cosine weighting isn't arbitrary - it emerges from the physics of how light flux spreads across surfaces.

**Frame Construction** becomes necessary because shading calculations need a complete coordinate system at each surface point, not just the normal. The Frame structure provides an orthonormal basis aligned with the surface, enabling future anisotropic shading and proper BRDF evaluation.

### Architectural Patterns Established

This phase establishes several critical patterns:

1. **Lighting as a Separate Concern** - Light management independent from shading
2. **Shadow Rays as Specialized Queries** - Optimized occlusion vs full intersection
3. **Frame-Based Shading** - Complete coordinate systems at hit points
4. **Direct vs Indirect Illumination** - Clear separation of lighting paths

### What Changes After Phase 6

Before Phase 6: Objects show only their intrinsic color (albedo), appearing flat.

After Phase 6:
- Surfaces show shading based on angle to light
- Shadows appear where objects block light
- The sphere appears three-dimensional with clear light and shadow sides
- The foundation for complex illumination is in place

The sphere with one bright side and shadows beneath proves our direct lighting pipeline works correctly from light sampling through shadow testing to shading evaluation.

## Implementation Sketch

### Extended Hit Structure

```glsl
struct Hit {
  Point p;          // Position of intersection
  vec3 n;           // Surface normal
  float t;          // Distance along ray
  int material_to;  // Material ID
  Frame frame;      // NEW: Complete orthonormal basis
}

struct Frame {
  vec3 t;  // Tangent (perpendicular to normal)
  vec3 b;  // Bitangent (perpendicular to both)
  vec3 n;  // Normal (same as hit.n, but part of frame)
}
```

The Frame provides a complete coordinate system aligned with the surface. This becomes essential for anisotropic materials and importance sampling, but even for Lambert shading it ensures our calculations are properly oriented.

### Lighting Module (`modules/lighting/point-light.ts`)

```typescript
const pointLight: ModuleDescriptor = {
  id: { kind: 'lighting', name: 'point-light', version: '1.0.0' },
  
  fragment: {
    uniforms: `
      uniform vec3 u_light_position;
      uniform vec3 u_light_radiance;  // Color * intensity
    `,
    
    functions: `
      LightSample lighting_sample(Point p) {
        // Sample the point light from point p
        // For point lights, "sampling" is deterministic
        
        LightSample ls;
        ls.position = u_light_position;
        ls.wi = normalize(u_light_position - p);  // Direction to light
        ls.distance = length(u_light_position - p);
        
        // Inverse square falloff
        ls.radiance = u_light_radiance / (ls.distance * ls.distance);
        
        return ls;
      }
    `
  },
  
  exports: ['lighting_sample']
};
```

The Lighting module provides light sampling - given a point in space, it returns information about how to reach lights and how bright they are. The inverse square falloff is physically correct for point sources.

### Extended Scene Module

```glsl
bool scene_intersect_any(Ray ray, float max_distance) {
  // Optimized occlusion query
  // Just returns true if ray hits anything before max_distance
  // Doesn't compute hit details
  
  float t = 0.0;
  
  for (int step = 0; step < MAX_STEPS; step++) {
    Point p = geometry_geodesic(ray.origin, ray.direction, t);
    float d = sphere_sdf(p);
    
    if (d < EPSILON) {
      return true;  // Hit something - blocked
    }
    
    t += d;
    if (t > max_distance) {
      return false;  // Reached light without hitting
    }
  }
  
  return false;
}
```

The "any" variant doesn't need to compute normals or materials - it just reports whether the path is blocked. This makes shadow rays significantly faster than full intersection.

### Enhanced Interaction Module

```glsl
vec3 interaction_surface_shade(vec3 wi, vec3 wo, Hit hit) {
  // Lambert shading with direct lighting
  // wi: direction to light
  // wo: direction to viewer
  
  MaterialProperties props = scene_material_properties(
    hit.material_to, hit.p
  );
  
  // Lambert BRDF: albedo/pi * cos(theta)
  float cos_theta = max(0.0, dot(wi, hit.n));
  vec3 brdf = props.albedo / PI;
  
  return brdf * cos_theta;
}
```

Lambert shading depends only on the angle between surface normal and light direction. The division by π ensures energy conservation - a perfectly white Lambert surface can't reflect more light than it receives.

### Enhanced Transport Module

```typescript
const directLightingTransport: ModuleDescriptor = {
  id: { kind: 'transport', name: 'direct-lighting', version: '1.0.0' },
  
  fragment: {
    functions: `
      vec3 transport_trace(Ray ray) {
        Hit hit;
        if (!scene_intersect(ray, hit)) {
          return vec3(0.0);  // Background
        }
        
        // Build complete frame at hit point
        hit.frame = geometry_frame(hit.p, hit.n);
        
        // Sample light source
        LightSample ls = lighting_sample(hit.p);
        
        // Check for shadows
        Ray shadow_ray;
        shadow_ray.origin = hit.p + hit.n * EPSILON;  // Offset to avoid self-intersection
        shadow_ray.direction = ls.wi;
        
        if (scene_intersect_any(shadow_ray, ls.distance)) {
          // In shadow - no direct light
          return vec3(0.0);
        }
        
        // Compute shading
        vec3 wo = -ray.direction;  // Toward viewer
        vec3 shading = interaction_surface_shade(ls.wi, wo, hit);
        
        // Combine with light radiance
        return shading * ls.radiance;
      }
    `
  }
};
```

Transport orchestrates the complete direct lighting calculation: find surface, sample light, test visibility, compute shading, combine results. Each step is delegated to the appropriate module, maintaining clean architectural boundaries.

### Material Properties Extension

```glsl
struct MaterialProperties {
  vec3 albedo;

```

Adding emission now maintains consistency even though we won't use it until later phases. Objects can emit light (emission > 0) or just reflect it (emission = 0).
