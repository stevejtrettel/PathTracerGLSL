# Phase 18: SessionManager

## Goals and Purpose

Phase 18 introduces the SessionManager that enables perfect reproducibility - the ability to save the complete state of a research session and restore it exactly, even weeks later or on a different machine. We're solving a fundamental research requirement: every interesting result must be reproducible. When you discover an unexpected rendering artifact, tune parameters to achieve a specific look, or set up a complex comparison, you need to capture that exact state so you can return to it, share it with colleagues, or include it in publications.

The critical test here is complete state capture and restoration. This goes beyond just parameters - we need to preserve camera position, accumulation progress, render mode, active recipe, and even extension-specific state like UI panel positions or keyboard bindings. When you load a session, everything should be exactly as you left it, down to the number of accumulated samples and the current zoom level. This perfect reproducibility transforms research from ephemeral explorations to permanent, shareable discoveries.

## What We're Building

### The Session System

**Complete State Capture** gathers all information needed to recreate the current research state. The SessionManager traverses the entire application, collecting parameters from the ParameterStore, rendering state from the RenderCoordinator, recipe information from the RecipeManager, and extension state from each installed extension. This comprehensive capture ensures nothing is lost when saving a session.

**JSON Serialization** creates portable, human-readable session files that can be versioned, shared, and inspected. Rather than binary formats that might become unreadable, JSON sessions are text files you can examine, modify, and even create by hand. The serialization handles complex types like Float32Arrays and nested objects, converting everything to a format that survives round-trip serialization.

**Version Compatibility Checking** ensures sessions can be safely loaded across different versions of the application. The SessionManager records the version that created a session and checks compatibility when loading. For minor version differences, it might migrate the data; for major differences, it warns the user about potential incompatibilities. This versioning prevents crashes from loading incompatible sessions while enabling forward migration paths.

**Extension State Hooks** allow extensions to participate in session persistence. Extensions can implement `saveState()` and `restoreState()` methods that the SessionManager calls during save/load operations. This means a camera control extension can save its orbit position, a UI extension can save panel layouts, and experiment extensions can save their configuration - all transparently managed by the session system.

### Architectural Patterns Established

This phase establishes several critical patterns:

1. **Hierarchical State Collection** - Traverse app structure gathering state
2. **Version-Aware Serialization** - Include metadata for compatibility
3. **Extension Participation** - Hooks for extension state persistence
4. **Non-Intrusive Restoration** - Load without triggering side effects

### What Changes After Phase 18

Before Phase 18: State is ephemeral, lost when closing the application.

After Phase 18:
- Complete research sessions can be saved and restored

interface SessionData {
  // Metadata
  version: string;                   // Format version
  appVersion: string;                // Application version
  timestamp: number;                 // When saved
  
  // Core state
  activeRecipe: string;              // Current recipe ID
  parameters: Record<string, any>;   // All parameters
  
  // Rendering state
  renderMode: RenderMode;            // Current mode
  renderState: {
    sampleCount: number;             // Accumulated samples
    isRunning: boolean;              // Was rendering active
    totalRenderTime: number;         // Time spent rendering
  };
  
  // Recipe-specific state
  recipeStates: Record<string, RecipeState>;  // Per-recipe accumulation
  
  // Camera state
  camera: {
    position: vec3;
    target?: vec3;
    fov: number;
    // Extension might add more
  };
  
  // Extension states
  extensions: Record<string, any>;   // Extension-specific data
  
  // Optional metadata
  metadata?: {
    title?: string;                  // User-provided name
    description?: string;            // Notes about session
    tags?: string[];                 // Searchable tags
    thumbnail?: string;              // Base64 preview image
  };
}

interface RecipeState {
  sampleCount: number;
  lastRenderTime: number;
  // Could include compressed film buffer data
}

### SessionManager Implementation

```typescript
class SessionManager {
  private app: ResearchApp;
  private version = '1.0.0';  // Session format version
  
  constructor(app: ResearchApp) {
    this.app = app;
  }
  
  captureState(): SessionData {
    // Capture complete application state
    
    console.log('Capturing session state...');
    
    const session: SessionData = {
      // Metadata
      version: this.version,
      appVersion: APP_VERSION,
      timestamp: Date.now(),
      
      // Core state
      activeRecipe: this.app.recipeManager.getActiveRecipeId(),
      parameters: this.captureParameters(),
      
      // Rendering state
      renderMode: this.app.renderCoordinator.getMode(),
      renderState: this.captureRenderState(),
      
      // Recipe states
      recipeStates: this.captureRecipeStates(),
      
      // Camera
      camera: this.captureCamera(),
      
      // Extensions
      extensions: this.captureExtensionStates()
    };
    
    return session;
  }
  
  private captureParameters(): Record<string, any> {
    // Get all parameters from store
    
    const params: Record<string, any> = {};
    
    for (const [key, value] of this.app.parameterStore.entries()) {
      // Handle special types
      if (value instanceof Float32Array) {
        params[key] = Array.from(value);
      } else if (value && typeof value === 'object') {
        params[key] = JSON.parse(JSON.stringify(value));  // Deep copy
      } else {
        params[key] = value;
      }
    }
    
    return params;
  }
  
  private captureRenderState(): any {
    // Get current rendering state
    
    const coordinator = this.app.renderCoordinator;
    
    return {
      sampleCount: coordinator.getSampleCount(),
      isRunning: coordinator.isRunning(),
      totalRenderTime: coordinator.getTotalRenderTime()
    };
  }
  
  private captureRecipeStates(): Record<string, RecipeState> {
    // Get per-recipe accumulation states
    
    const states: Record<string, RecipeState> = {};
    
    for (const recipeId of this.app.recipeManager.getRecipeIds()) {
      const resources = this.app.recipeManager.getRecipeResources(recipeId);
      
      states[recipeId] = {
        sampleCount: resources.accumulator.sampleCount,
        lastRenderTime: resources.accumulator.lastRenderTime
      };
    }
    
    return states;
  }
  
  private captureExtensionStates(): Record<string, any> {
    // Let each extension save its state
    
    const states: Record<string, any> = {};
    
    for (const [name, extension] of this.app.extensions) {
      if (typeof extension.saveState === 'function') {
        try {
          const state = extension.saveState();
          if (state !== undefined) {
            states[name] = state;
          }
        } catch (error) {
          console.error(`Failed to save state for extension '${name}':`, error);
        }
      }
    }
    
    return states;
  }
  
  private captureCamera(): any {
    // Try to get camera from extensions first
    const cameraControls = this.app.getService('camera-controls');
    if (cameraControls && typeof cameraControls.getCamera === 'function') {
      return cameraControls.getCamera();
    }
    
    // Fallback to parameters
    return {
      position: this.app.parameterStore.get('camera.position') || [0, 0, 5],
      fov: this.app.parameterStore.get('camera.fov') || 60
    };
  }
}
```

### Session Restoration

```typescript
class SessionManager {
  async restoreState(session: SessionData): Promise<void> {
    // Restore complete application state
    
    console.log('Restoring session...');
    
    // Check version compatibility
    if (!this.isCompatibleVersion(session.version)) {
      const proceed = await this.promptVersionWarning(session.version);
      if (!proceed) return;
    }
    
    // Stop rendering during restoration
    const wasRunning = this.app.renderCoordinator.isRunning();
    if (wasRunning) {
      this.app.renderCoordinator.stop();
    }
    
    // Restore in specific order to avoid side effects
    
    // 1. Switch to saved recipe (already compiled)
    if (session.activeRecipe) {
      this.app.recipeManager.switchToRecipe(session.activeRecipe);
    }
    
    // 2. Restore parameters silently (no onChange events)
    this.restoreParameters(session.parameters);
    
    // 3. Restore per-recipe states
    this.restoreRecipeStates(session.recipeStates);
    
    // 4. Restore render mode
    if (session.renderMode) {
      this.app.renderCoordinator.setMode(session.renderMode);
    }
    
    // 5. Restore camera
    this.restoreCamera(session.camera);
    
    // 6. Restore extension states
    this.restoreExtensionStates(session.extensions);
    
    // 7. Resume rendering if it was running
    if (session.renderState?.isRunning || wasRunning) {
      this.app.renderCoordinator.start();
    }
    
    console.log('Session restored successfully');
    
    // Emit event for extensions
    this.app.eventBus.emit('session.restored', { session });
  }
  
  private restoreParameters(parameters: Record<string, any>): void {
    // Restore all parameters without triggering resets
    
    // Temporarily disable onChange to avoid cascading updates
    const originalOnChange = this.app.parameterStore.onChange;
    this.app.parameterStore.onChange = null;
    
    for (const [key, value] of Object.entries(parameters)) {
      this.app.parameterStore.set(key, value, 'session');
    }
    
    // Restore onChange
    this.app.parameterStore.onChange = originalOnChange;
    
    // Single batch update to GPU
    this.app.engine.updateAllUniforms(parameters);
  }
  
  private restoreRecipeStates(states: Record<string, RecipeState>): void {
    // Restore per-recipe accumulation
    
    for (const [recipeId, state] of Object.entries(states)) {
      const resources = this.app.recipeManager.getRecipeResources(recipeId);
      if (resources) {
        resources.accumulator.sampleCount = state.sampleCount;
        resources.accumulator.lastRenderTime = state.lastRenderTime;
      }
    }
  }
  
  private restoreExtensionStates(states: Record<string, any>): void {
    // Let each extension restore its state
    
    for (const [name, state] of Object.entries(states)) {
      const extension = this.app.extensions.get(name);
      
      if (extension && typeof extension.restoreState === 'function') {
        try {
          extension.restoreState(state);
        } catch (error) {
          console.error(`Failed to restore state for extension '${name}':`, error);
        }
      }
    }
  }
}
```

Restoration carefully rebuilds state without triggering side effects.

### File Operations

```typescript
class SessionManager {
  async save(filename?: string): Promise<string> {
    // Save session to file
    
    const session = this.captureState();
    
    // Add metadata
    session.metadata = {
      title: filename || `session-${Date.now()}`,
      thumbnail: await this.captureThumbnail()
    };
    
    const json = JSON.stringify(session, null, 2);
    
    // Browser environment
    if (typeof window !== 'undefined') {
      const blob = new Blob([json], { type: 'application/json' });
      const url = URL.createObjectURL(blob);
      
      const a = document.createElement('a');
      a.href = url;
      a.download = filename || `session-${Date.now()}.json`;
      a.click();
      
      URL.revokeObjectURL(url);
      
      return a.download;
    }
    
    // Node environment (for testing)
    const fs = require('fs').promises;
    const path = filename || `session-${Date.now()}.json`;
    await fs.writeFile(path, json, 'utf8');
    
    return path;
  }
  
  async load(file: File | string): Promise<void> {
    // Load session from file
    
    let json: string;
    
    if (typeof file === 'string') {
      // Path to file (Node) or JSON string
      if (file.startsWith('{')) {
        json = file;
      } else {
        const fs = require('fs').promises;
        json = await fs.readFile(file, 'utf8');
      }
    } else {
      // File object (browser)
      json = await file.text();
    }
    
    const session = JSON.parse(json) as SessionData;
    
    // Validate before restoring
    this.validateSession(session);
    
    await this.restoreState(session);
  }
  
  private validateSession(session: any): void {
    // Validate session structure
    
    if (!session.version) {
      throw new Error('Invalid session: missing version');
    }
    
    if (!session.parameters) {
      throw new Error('Invalid session: missing parameters');
    }
    
    // Could validate against schema
  }
}
```

### Version Management

```typescript
class SessionManager {
  private isCompatibleVersion(sessionVersion: string): boolean {
    // Check if session version is compatible
    
    const [sessionMajor] = sessionVersion.split('.');
    const [currentMajor] = this.version.split('.');
    
    // Major version must match
    return sessionMajor === currentMajor;
  }
  
  private async migrateSession(session: SessionData): Promise<SessionData> {
    // Migrate old session format to current
    
    const [major, minor] = session.version.split('.').map(Number);
    
    // Apply migrations sequentially
    if (major === 0 && minor < 9) {
      session = this.migrateFrom_0_8_to_0_9(session);
    }
    
    if (major === 0 && minor < 10) {
      session = this.migrateFrom_0_9_to_1_0(session);
    }
    
    session.version = this.version;
    return session;
  }
  
  private migrateFrom_0_9_to_1_0(session: any): SessionData {
    // Example migration
    
    // Rename old field
    if (session.renderer) {
      session.activeRecipe = session.renderer;
      delete session.renderer;
    }
    
    // Add new required field
    if (!session.recipeStates) {
      session.recipeStates = {};
    }
    
    return session;
  }
}
```

### Extension State Example

```typescript
class CameraControlsExtension implements Extension {
  name = 'camera-controls';
  
  private state = {
    mode: 'orbit' as 'orbit' | 'fly' | 'turntable',
    orbitRadius: 5,
    orbitTheta: 0,
    orbitPhi: Math.PI / 4,
    target: [0, 0, 0] as vec3
  };
  
  saveState(): any {
    // Return serializable state
    return {
      mode: this.state.mode,
      orbitRadius: this.state.orbitRadius,
      orbitTheta: this.state.orbitTheta,
      orbitPhi: this.state.orbitPhi,
      target: [...this.state.target]
    };
  }
  
  restoreState(saved: any): void {
    // Restore from saved state
    if (saved.mode) this.state.mode = saved.mode;
    if (saved.orbitRadius) this.state.orbitRadius = saved.orbitRadius;
    if (saved.orbitTheta) this.state.orbitTheta = saved.orbitTheta;
    if (saved.orbitPhi) this.state.orbitPhi = saved.orbitPhi;
    if (saved.target) this.state.target = saved.target;
    
    // Apply restored state
    this.updateCamera();
  }
}
```
