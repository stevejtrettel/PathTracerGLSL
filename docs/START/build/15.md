# Phase 15: Full Transport Features

## Goals and Purpose

Phase 15 completes our transport system by adding volume rendering, proper material interfaces for glass and dielectrics, and the sophisticated sampling strategies needed for production rendering. We're solving the complex light transport problems that make the difference between a research prototype and a production renderer: light scattering through fog and clouds, refraction through glass and water, and the intricate behavior of nested transparent objects like a glass of water with ice cubes.

The critical test here is that our transport system correctly handles material transitions at every interface. When light enters glass from air, the refractive indices determine both reflection and transmission. When it travels through fog, scattering and absorption attenuate and redirect it. When it encounters nested dielectrics - glass within water within air - our material_from/material_to tracking ensures correct behavior at each boundary. This phase proves our architecture supports the full complexity of physical light transport.

## What We're Building

### The Volume Transport System

**Delta Tracking** implements unbiased volume rendering through stochastic sampling of the medium. As rays travel through participating media like fog or smoke, delta tracking decides probabilistically where scattering events occur. The algorithm uses a majorant to bound spatially-varying density, taking "null collision" steps that maintain mathematical correctness while adapting to heterogeneous media. This elegant technique handles everything from uniform fog to complex smoke simulations.

**Woodcock Tracking** (the heart of delta tracking) marches through volumes using the maximum density as a conservative bound, then randomly accepts or rejects collision points based on the local density ratio. This rejection sampling approach means we can handle arbitrary density variations without bias. The "null collisions" where we reject but continue marching ensure the algorithm remains mathematically correct regardless of density variations.

**Material Interface Stack** tracks which materials rays are traveling through, crucial for nested dielectrics. When light enters a glass sphere sitting in water, we need to know we're going from water into glass, not air into glass. The material_from and material_to fields in our Hit structure, combined with careful interface resolution, maintain this stack implicitly through geometric queries rather than explicit tracking.

**Dielectric Transport** handles refraction and total internal reflection at material boundaries. Using Snell's law and Fresnel equations, we determine how much light reflects versus transmits at each interface, and in which directions. The critical angle for total internal reflection emerges naturally from the physics, creating the caustics and light patterns that make glass and water appear realistic.

// Query material at any point in space
int scene_material_at(vec3 p) {
  // Determine which material contains point p
  // Uses inside/outside testing of SDFs
  
  int material = MATERIAL_AIR;  // Default to air
  float min_interior = 0.0;
  
  // Check all objects to find deepest container
  for (int i = 0; i < NUM_OBJECTS; i++) {
    float d = evaluate_object_sdf(i, p);
    
    if (d < 0.0) {  // Inside this object
      // Use most deeply nested object
      if (-d > min_interior) {
        min_interior = -d;
        material = object_material[i];
      }
    }
  }
  
  return material;
}

// Get density at point for heterogeneous volumes
float scene_density_at(vec3 p, int material) {
  // For now, return uniform density
  // Future: procedural noise, voxel grids, etc.
  
  MaterialProperties props = scene_material_properties(material, p);
  
  if (!props.is_volume) return 0.0;
  
  // Uniform density based on extinction
  vec3 sigma_t = props.sigma_s + props.sigma_a;
  return length(sigma_t) * props.density_scale;
}

### Complete Interface Resolution

```glsl
void resolve_complete_interface(Ray ray, inout Hit hit) {
  // Determine materials on both sides of interface
  // Handles nested dielectrics correctly
  
  // Offset points for material queries
  vec3 p_along_ray = hit.p - hit.n * EPSILON * 2.0;
  vec3 p_against_ray = hit.p + hit.n * EPSILON * 2.0;
  
  // Query materials
  int mat_along = scene_material_at(p_along_ray);
  int mat_against = scene_material_at(p_against_ray);
  
  // Determine which is from and which is to
  float cos_theta = dot(ray.direction, hit.n);
  
  if (cos_theta < 0.0) {
    // Ray hitting from outside (along normal)
    hit.material_from = mat_against;
    hit.material_to = mat_along;
  } else {
    // Ray hitting from inside (against normal)
    hit.material_from = mat_along;  
    hit.material_to = mat_against;
    hit.n = -hit.n;  // Flip normal for consistent orientation
  }
  
  // Store IOR ratio for refraction
  MaterialProperties props_from = scene_material_properties(
    hit.material_from, hit.p
  );
  MaterialProperties props_to = scene_material_properties(
    hit.material_to, hit.p
  );
  
  hit.ior_ratio = props_from.ior / props_to.ior;
}
```

Complete interface resolution handles arbitrary nesting of materials.

### Delta Tracking Implementation

```glsl
vec3 transport_through_volume(
  Ray ray,
  float max_distance,
  int material,
  inout vec3 throughput,
  inout float distance_traveled
) {
  // Delta tracking through participating medium
  
  MaterialProperties props = scene_material_properties(material, ray.origin);
  
  if (!props.is_volume) {
    // No volume - just travel through
    distance_traveled = max_distance;
    return vec3(0.0);  // No volume contribution
  }
  
  vec3 sigma_s = props.sigma_s;
  vec3 sigma_a = props.sigma_a;
  vec3 sigma_t = sigma_s + sigma_a;
  float sigma_max = max(max(sigma_t.x, sigma_t.y), sigma_t.z);
  
  if (sigma_max < EPSILON) {
    // Effectively empty volume
    distance_traveled = max_distance;
    return vec3(0.0);
  }
  
  vec3 volume_radiance = vec3(0.0);
  float t = 0.0;
  
  while (t < max_distance) {
    // Sample free path length
    float free_path = -log(max(EPSILON, next_1d())) / sigma_max;
    t += free_path;
    
    if (t >= max_distance) {
      // Exited volume
      distance_traveled = max_distance;
      
      // Apply remaining attenuation
      vec3 transmittance = exp(-sigma_t * (max_distance - (t - free_path)));
      throughput *= transmittance;
      break;
    }
    
    // Current position
    vec3 p = ray.origin + ray.direction * t;
    
    // Get local density (may vary spatially)
    float density = scene_density_at(p, material);
    vec3 sigma_t_local = sigma_t * (density / sigma_max);
    
    // Russian roulette for null collision
    float p_real = length(sigma_t_local) / sigma_max;
    
    if (next_1d() < p_real) {
      // Real collision - scatter or absorb
      
      // Probability of scattering vs absorption
      float p_scatter = length(sigma_s) / max(EPSILON, length(sigma_t_local));
      
      if (next_1d() < p_scatter) {
        // Scatter event
        
        // Apply attenuation up to this point
        vec3 transmittance = exp(-sigma_t * t);
        
        // Sample phase function for new direction
        float phase_pdf;
        vec3 wo = sample_phase_function(
          -ray.direction,
          props.g,
          next_2d(),
          phase_pdf
        );
        
        // Add emission from volume
        volume_radiance += throughput * transmittance * props.emission;
        
        // Update throughput for scattered ray
        throughput *= transmittance * sigma_s / sigma_t_local;
        
        // Set up scattered ray
        ray.origin = p;
        ray.direction = wo;
        distance_traveled = t;
        
        return volume_radiance;  // Continue from scatter point
      } else {
        // Absorption - terminate path
        distance_traveled = t;
        return volume_radiance;
      }
    }
    // Null collision - continue marching
  }
  
  return volume_radiance;
}
```

Delta tracking handles heterogeneous media with unbiased sampling.

### Phase Function Sampling

```glsl
vec3 sample_phase_function(vec3 wi, float g, vec2 xi, out float pdf) {
  // Henyey-Greenstein phase function sampling
  
  if (abs(g) < 0.001) {
    // Isotropic scattering
    return sample_sphere_uniform(xi, pdf);
  }
  
  // Sample HG distribution
  float cos_theta = 0.0;
  if (abs(g) < 0.999) {
    float s = 2.0 * xi.x - 1.0;
    float denom = 1.0 + g * s;
    cos_theta = (1.0 + g*g - ((1.0 - g*g) / denom) * ((1.0 - g*g) / denom)) / (2.0 * g);
  } else {
    // Nearly forward/backward scattering
    cos_theta = xi.x < 0.5 ? 1.0 : -1.0;
  }
  
  // Generate direction around wi
  float sin_theta = sqrt(max(0.0, 1.0 - cos_theta * cos_theta));
  float phi = 2.0 * PI * xi.y;
  
  // Build local frame around wi
  vec3 u, v;
  make_orthonormal_basis(wi, u, v);
  
  vec3 wo = sin_theta * cos(phi) * u +
            sin_theta * sin(phi) * v +
            cos_theta * wi;
  
  // Evaluate PDF
  float denom = 1.0 + g*g - 2.0*g*cos_theta;
  pdf = (1.0 - g*g) / (4.0 * PI * denom * sqrt(denom));
  
  return normalize(wo);
}
```

Phase functions control directional scattering in volumes.

### Dielectric Refraction

```glsl
vec3 refract_dielectric(vec3 wi, vec3 n, float ior_ratio, out bool total_internal_reflection) {
  // Snell's law refraction
  
  float cos_theta_i = -dot(wi, n);
  float sin2_theta_i = max(0.0, 1.0 - cos_theta_i * cos_theta_i);
  float sin2_theta_t = ior_ratio * ior_ratio * sin2_theta_i;
  
  // Check for total internal reflection
  if (sin2_theta_t >= 1.0) {
    total_internal_reflection = true;
    return vec3(0.0);  // No refraction possible
  }
  
  total_internal_reflection = false;
  float cos_theta_t = sqrt(1.0 - sin2_theta_t);
  
  return ior_ratio * wi + (ior_ratio * cos_theta_i - cos_theta_t) * n;
}

float fresnel_dielectric(float cos_theta_i, float ior_ratio) {
  // Schlick's approximation for dielectric Fresnel
  
  float f0 = (1.0 - ior_ratio) / (1.0 + ior_ratio);
  f0 = f0 * f0;
  
  float cos_theta = min(cos_theta_i, 1.0);
  return f0 + (1.0 - f0) * pow(1.0 - cos_theta, 5.0);
}
```

Dielectric interfaces handle refraction and reflection with proper Fresnel weights.

### Integrated Surface and Volume Transport

```glsl
vec3 transport_trace(Ray ray) {
  vec3 throughput = vec3(1.0);
  vec3 radiance = vec3(0.0);
  
  for (int bounce = 0; bounce < MAX_BOUNCES; bounce++) {
    // Check current medium
    int current_material = scene_material_at(ray.origin);
    MaterialProperties current_props = scene_material_properties(
      current_material, ray.origin
    );
    
    // Find next surface
    Hit hit;
    bool found_surface = scene_intersect(ray, hit);
    float surface_distance = found_surface ? hit.t : MAX_DIST;
    
    // Transport through volume (if any)
    if (current_props.is_volume) {
      float volume_distance = 0.0;
      vec3 volume_contribution = transport_through_volume(
        ray, surface_distance, current_material, 
        throughput, volume_distance
      );
      
      radiance += volume_contribution;
      
      if (volume_distance < surface_distance) {
        // Scattered in volume - continue from scatter point
        continue;
      }
    }
    
    if (!found_surface) break;
    
    // Resolve interface completely
    resolve_complete_interface(ray, hit);
    
    // Handle surface interaction
    MaterialProperties props_to = scene_material_properties(
      hit.material_to, hit.p
    );
    
    // [Handle emission, NEE, surface scattering as before]
    
    // Special handling for dielectrics
    if (props_to.is_dielectric) {
      float F = fresnel_dielectric(abs(dot(ray.direction, hit.n)), hit.ior_ratio);
      
      if (next_1d() < F) {
        // Reflect
        ray.direction = reflect(ray.direction, hit.n);
      } else {
        // Refract
        bool tir;
        vec3 refracted = refract_dielectric(ray.direction, hit.n, hit.ior_ratio, tir);
        
        if (tir) {
          // Total internal reflection
          ray.direction = reflect(ray.direction, hit.n);
        } else {
          ray.direction = refracted;
          throughput *= hit.ior_ratio * hit.ior_ratio;  // Radiance correction
        }
      }
      
      ray.origin = hit.p + ray.direction * EPSILON * 10.0;
      continue;
    }
    
    // [Regular surface scattering for non-dielectrics]
  }
  
  return radiance;
}
```
