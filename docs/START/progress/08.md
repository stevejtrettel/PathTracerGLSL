# Phase 8 Engine Architecture Document

## Overview

The engine implements a modular path tracing renderer with progressive accumulation using WebGL2. It features a two-pass HDR rendering pipeline where radiance accumulates in linear space over multiple frames, then gets tone-mapped for display.

## Core Architecture

### Component Responsibilities

```
┌─────────────┐
│   Engine    │  Orchestrates rendering pipeline
└──────┬──────┘
       │

│  │  modules   │  │  2 programs  │           │

│                         │                    │
│  ┌──────────────────────▼────────────────┐  │
│  │          RenderExecutor                │  │
│  │                                        │  │

│  └────────────────────────────────────────┘  │
│                                               │
│  ┌────────────────────────────────────────┐  │

```

### Two-Pass Rendering Pipeline

```
Frame N:
┌────────────────────────────────────────────────────┐
│ Pass 1: Accumulation (Main Program)               │
├────────────────────────────────────────────────────┤
│ Input:  u_accumulator_radiance_previous (frame N-1)│
│ Process: Ray trace → Accumulate                   │
│ Output: Radiance to framebuffer (HDR RGBA32F)     │
└────────────────────────────────────────────────────┘
                          ↓
┌────────────────────────────────────────────────────┐
│ Pass 2: Display (Display Program)                 │
├────────────────────────────────────────────────────┤
│ Input:  u_radiance_texture (accumulated radiance) │
│ Process: Tone mapping + gamma correction          │
│ Output: RGB to screen (LDR)                       │
└────────────────────────────────────────────────────┘
```

## Module System

### Module Structure

Each module provides KIND-prefixed functions that get concatenated directly into shaders:

```typescript
interface ModuleDescriptor {
    id: {
        kind: ModuleKind;     // 'camera', 'transport', etc.
        name: string;         // 'pinhole', 'pathtracer', etc.
        version: string;
    };
    fragment: {
        uniforms?: string;    // GLSL uniform declarations
        constants?: string;   // GLSL constants
        functions: string;    // KIND-prefixed functions
    };
    uniformBindings?: UniformBinding[];  // Parameter → uniform mappings
    exports: string[];        // Exported function names
}
```

### Module Execution Order

Fixed pipeline order enforced by `MODULE_ORDER`:

1. **Ambient** - Mathematical foundations (`ambient_geodesic`)
2. **Scene** - Object intersection (`scene_intersect`)
3. **Lighting** - Light sources (`lighting_sample`)
4. **Camera** - Ray generation (`camera_generateRay`)
5. **Transport** - Integration (`transport_trace`)
6. **Interaction** - BRDFs (`interaction_scatter`)
7. **Accumulator** - Frame blending (`accumulator_accumulate`)
8. **Developer** - Tone mapping (`developer_develop`)

### Main Function Generation

The compiler generates a main function using KIND prefixes:

```glsl
void main() {
    vec2 pixel = gl_FragCoord.xy;
    uint rng_state = hash3(uint(pixel.x), uint(pixel.y), uint(u_frame_index));
    vec2 xi = random2(rng_state);
    
    Ray ray = camera_generateRay(pixel, xi);        // KIND prefix
    Spectrum spectrum = transport_trace(ray);       // KIND prefix
    Radiance radiance = accumulator_accumulate(spectrum, pixel);
    
    // Output radiance for accumulation (no developer)
    fragColor = vec4(radiance, 1.0);
}
```

## Parameter System

### Flow Architecture

```
User Input → ParameterStore → Engine → ShaderCompiler → GPU
             ├─ Validation
             ├─ Change batching
             └─ onChange callback
```

### ParameterStore

Central parameter management with change notification:

```typescript
class ParameterStore {
    private parameters = new Map<string, any>();
    onChange?: (changes: ParameterChanges) => void;
    
    set(path: string, value: any): void {
        const oldValue = this.parameters.get(path);
        this.parameters.set(path, value);
        
        if (this.onChange) {
            this.onChange({
                changes: [{
                    path,
                    oldValue,
                    newValue: value,
                    timestamp: Date.now()
                }],
                source: 'user',
                triggersReset: this.shouldReset(path)
            });
        }
    }
}
```

### Parameter Paths

Hierarchical dot-notation paths map to shader uniforms:

```
Parameter Path          → GLSL Uniform Name
camera.position        → u_camera_position
camera.fov            → u_camera_fov
light.intensity       → u_light_intensity
accumulator.reset     → u_accumulator_reset
```

### Uniform Binding

Modules declare parameter bindings:

```typescript
uniformBindings: [
    {
        uniform: 'u_camera_position',
        parameters: ['camera.position'],
        compute: (params) => params['camera.position']
    },
    {
        uniform: 'u_camera_matrix',
        parameters: ['camera.position', 'camera.target'],
        compute: (params) => computeViewMatrix(
            params['camera.position'],
            params['camera.target']
        )
    }
]
```

## Shader Compilation

### ShaderCompiler Responsibilities

1. **Compilation**: Builds main and display programs
2. **Uniform Management**: Caches locations and values
3. **Update Distribution**: Routes parameter changes to GPU

### Two-Program Architecture

```typescript
class ShaderCompiler {
    private mainProgram: WebGLProgram;     // Accumulation
    private displayProgram: WebGLProgram;  // Tone mapping
    
    compile(modules: ModuleDescriptor[]): void {
        // Main: All modules except developer
        this.mainProgram = this.buildMainShader(modules);
        
        // Display: Minimal shader with just developer
        this.displayProgram = this.buildDisplayShader(modules);
    }
}
```

### Uniform Caching

Prevents redundant GPU updates:

```typescript
updateUniforms(changes: ParameterChanges): void {
    for (const change of changes.changes) {
        const cached = this.uniformValueCache.get(change.path);
        
        // Skip if value unchanged
        if (this.valuesEqual(cached, change.newValue)) {
            this.updateStats.skipped++;
            continue;
        }
        
        // Update cache and GPU
        this.uniformValueCache.set(change.path, change.newValue);
        this.gl.uniform3fv(location, change.newValue);
        this.updateStats.total++;
    }
}
```

## Resource Management

### Ping-Pong Buffers

HDR accumulation using double buffering:

```typescript
class ResourceManager {
    private textures: {
        current: WebGLTexture;   // Being written
        previous: WebGLTexture;  // Being read
    };
    
    prepareFrame(): void {
        // Bind previous for reading
        gl.activeTexture(gl.TEXTURE0);
        gl.bindTexture(gl.TEXTURE_2D, this.textures.previous);
        
        // Set current as render target
        gl.bindFramebuffer(gl.FRAMEBUFFER, this.framebuffers.current);
    }
    
    finalizeFrame(): void {
        // Swap for next frame
        [this.textures.current, this.textures.previous] = 
            [this.textures.previous, this.textures.current];
    }
}
```

### Texture Format

RGBA32F for full HDR precision:
- 32 bits per channel
- Full floating point range
- No clamping to [0,1]
- Allows radiance accumulation

## Render Execution

### RenderExecutor Responsibilities

Executes both rendering passes:

```typescript
class RenderExecutor {
    executeMainPass(): void {
        gl.useProgram(this.mainProgram);
        gl.drawArrays(gl.TRIANGLES, 0, 3);  // Fullscreen triangle
    }
    
    executeDisplayPass(radianceTexture: WebGLTexture): void {
        gl.bindFramebuffer(gl.FRAMEBUFFER, null);  // Screen
        gl.useProgram(this.displayProgram);
        
        gl.activeTexture(gl.TEXTURE0);
        gl.bindTexture(gl.TEXTURE_2D, radianceTexture);
        gl.uniform1i(radianceUniformLoc, 0);
        
        gl.drawArrays(gl.TRIANGLES, 0, 3);
    }
}
```

## Frame Lifecycle

Complete frame rendering sequence:

```typescript
Engine.renderFrame() {
    // 1. Setup
    resources.prepareFrame();           // Bind previous, set target
    
    // 2. Update
    compiler.updateEngineUniforms({     // Frame-specific uniforms
        resolution: [width, height],
        frameIndex: this.frameCount,
        sampleCount: this.sampleCount,
        time: this.time
    });
    
    // 3. Accumulation pass
    executor.executeMainPass();         // Trace + accumulate
    
    // 4. Display pass  
    const radiance = resources.getCurrentTexture();
    executor.executeDisplayPass(radiance);  // Tone map to screen
    
    // 5. Finalize
    resources.finalizeFrame();          // Swap buffers
    
    this.frameCount++;
    this.sampleCount++;
}
```

## Progressive Accumulation

### Sample Accumulation

The averaging accumulator blends samples over time:

```glsl
Radiance accumulator_accumulate(Spectrum new_sample, vec2 pixel) {
    if (u_sample_count == 0 || u_accumulator_reset) {
        return Radiance(new_sample);
    }
    
    vec2 uv = pixel / u_resolution;
    vec3 previous = texture(u_accumulator_radiance_previous, uv).rgb;
    
    float n = float(u_sample_count);
    vec3 result = previous * (n / (n + 1.0)) + new_sample * (1.0 / (n + 1.0));
    
    return Radiance(result);
}
```

### Reset Conditions

Accumulation resets when:
- Camera moves
- Light parameters change
- Scene changes
- Manual reset requested

## Application Layer

### MinimalApp Integration

```typescript
class MinimalApp {
    constructor(canvas: HTMLCanvasElement) {
        const gl = canvas.getContext('webgl2', {
            antialias: false,  // Required for framebuffer blit
            preserveDrawingBuffer: true
        });
        
        this.engine = new Engine(gl);
        this.parameterStore = new ParameterStore();
        
        // Wire parameters to engine
        this.parameterStore.onChange = (changes) => {
            // Reset on camera/light changes
            if (this.shouldReset(changes)) {
                this.engine.clearAccumulation();
            }
            this.engine.updateParameters(changes);
        };
    }
    
    startRenderLoop(): void {
        const loop = () => {
            this.engine.renderFrame();
            requestAnimationFrame(loop);
        };
        loop();
    }
}
```

## Performance Characteristics

- **Shader compilation**: ~150ms per recipe at startup
- **Uniform updates**: < 0.1ms with caching (60-80% skip rate)
- **Frame time**: 2-3ms typical (accumulation + display)
- **Memory usage**: ~67MB for 1920×1080 HDR buffers (2×RGBA32F)
- **Convergence**: 100-1000 samples for clean image

## Future Considerations

The architecture supports future expansion:
- Multiple recipes (would need per-recipe resource management)
- Shadow maps (additional pre-pass)
- Multiple importance sampling (modify transport)
- Spectral rendering (change Spectrum typedef)

The WebGL2 limitation is the 16 texture unit maximum and lack of compute shaders. Major architectural changes would come with WebGPU migration.
