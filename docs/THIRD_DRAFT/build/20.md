# Phase 20: Production Features

## Goals and Purpose

Phase 20 completes our path tracer by adding the production features that transform it from a capable renderer into a comprehensive research tool. We're solving the final usability challenges: researchers need to run systematic experiments, capture and share results, visualize data in different ways, and render at resolutions beyond screen size. These features - parameter sweeps, screenshot export, advanced tone mapping, variance visualization, and tiled rendering - are what separate a prototype from a tool scientists actually use for their work.

The critical test here is that the system supports complete research workflows end-to-end. A researcher can set up parameter sweeps to explore material properties systematically, visualize convergence through variance displays, switch between photorealistic and diagnostic visualizations, and export publication-quality images at any resolution. These aren't just convenience features - they're essential for turning rendering experiments into scientific insights.

## What We're Building

### The Research Tool Extensions

**UI Panel System** provides rich visual interfaces beyond the simple stats overlay. We're building panels for parameter control with sliders and color pickers, experiment configuration with sweep ranges, and result visualization with convergence graphs. These panels use the extension system's service registry to discover parameters and coordinate with other extensions, creating a composable UI that grows with needs.

**Parameter Sweep Experiments** automate the systematic exploration of parameter spaces. Instead of manually adjusting roughness and taking screenshots, researchers define sweep ranges and sampling patterns, then let the system automatically render each configuration, save results, and generate comparison matrices. This transforms qualitative exploration into quantitative analysis.

**Export Infrastructure** handles the complete pipeline from pixels to publishable assets. This includes screenshot capture with metadata, EXR export for HDR data, session state embedding in images, and batch export for sweep results. Every exported image carries enough information to reproduce it exactly - parameters, random seeds, sample counts.

**Advanced Visualization Modes** extend the developer module with specialized tone mapping and analysis displays. ACES film emulation for photorealistic output, false color for luminance analysis, variance visualization for convergence debugging, and heatmaps for sampling density. These modes help researchers understand not just what the image looks like, but how the renderer produced it.

**Tiled Production Rendering** enables arbitrary resolution output by splitting the image into tiles that fit in GPU memory. Each tile renders to target quality, results are assembled into the final image, and progress is checkpointed to handle interruptions. This means researchers can render 16K images for print or detailed analysis without GPU limitations.
