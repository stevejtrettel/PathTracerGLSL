# Module Integration

## Purpose
Defines how World modules integrate with the Engine and Photography modules to form a complete shader.

## Module Loading

The Engine receives modules and concatenates them in a specific order:

```typescript
interface Recipe {
  world: {
    geometry: ModuleDescriptor;
    scene: ModuleDescriptor;
    lighting: ModuleDescriptor;
  };
  photography: {
    camera: ModuleDescriptor;
    transport: ModuleDescriptor;
    interaction: ModuleDescriptor;
    film: ModuleDescriptor;
    developer: ModuleDescriptor;
  };
}

// Concatenation order (critical!)
const shaderSource = [
  commonTypes,                    // Shared type definitions
  recipe.world.geometry,          // Mathematical foundation
  recipe.world.scene,            // Objects and materials
  recipe.world.lighting,         // Light sampling
  recipe.photography.camera,     // Ray generation
  recipe.photography.transport,  // Integration algorithms
  recipe.photography.interaction,// BRDFs (uses material properties)
  recipe.photography.film,       // Accumulation
  recipe.photography.developer,  // Tone mapping
  mainFunction                   // Entry point
].join('\n');
```

## Function Dependencies

### Transport → World

Transport calls World functions for intersection and lighting:

```glsl
// From Scene module
Hit hit;
if (scene_intersect(ray, hit)) {
  MaterialProperties props = scene_material_properties(hit.material_to, hit.p);
  // ...
}

// From Lighting module
LightSample ls = lighting_sample(hit.p, xi);
if (!scene_intersect_any(shadow_ray, ls.distance)) {
  // Light is visible
}
```

### Interaction → World

Interaction queries material properties for BRDF evaluation:

```glsl
Spectrum interaction_surface_shade(Direction wi, Direction wo, Hit hit) {
  // Get properties from Scene
  MaterialProperties props = scene_material_properties(hit.material_to, hit.p);
  
  // Use properties for BRDF
  float alpha = props.roughness * props.roughness;
  vec3 F = fresnel(props.ior, dot(wi, hit.n));
  // ...
}
```

### Camera → World

Camera may query scene bounds for focus distance:

```glsl
Ray camera_generate_ray(vec2 pixel, vec2 xi) {
  #ifdef AUTO_FOCUS
    float focus_distance = scene_bounding_radius() * 2.0;
  #endif
  // ...
}
```

## Uniform Management

Each module declares its uniforms, which the Engine must bind:

### Scene Module Uniforms
```glsl
// Material properties (from SceneCompiler)
uniform vec4 u_material_albedo_metallic[NUM_MATERIALS];
uniform vec4 u_material_ior_flags[NUM_MATERIALS];
uniform vec3 u_material_emission[NUM_MATERIALS];

// Object transforms (if not baked)
uniform mat4 u_object_transforms[NUM_OBJECTS];
```

### Lighting Module Uniforms
```glsl
// Light intensities (adjustable without recompilation)
uniform vec3 u_light_intensities[NUM_LIGHTS];

// Environment map
uniform sampler2D u_environment_map;
uniform float u_environment_intensity;
```

### Binding Contract
```typescript
interface UniformUpdate {
  module: 'scene' | 'lighting' | 'camera' | ...;
  name: string;
  value: any;
}

// Engine maintains uniform state
engine.updateUniform({
  module: 'scene',
  name: 'u_material_albedo_metallic',
  value: new Float32Array([...])  // Packed vec4 array
});
```

## Material ID Coordination

Material IDs must be consistent across modules:

```typescript
// Metadata passed from WorldCompiler to Engine
interface WorldMetadata {
  materialCount: number;        // How many materials exist
  materialIdMap: Map<string, number>;  // Name → ID mapping
  
  // Special IDs
  AIR_ID: 0;                   // Always 0
  firstLightMaterialId: number; // Where light materials start
}

// Transport needs to know valid material IDs for:
// - Importance sampling decisions
// - Volume tracking
// - Russian roulette
```

## Error States

The Engine must handle integration failures:

```typescript
class ShaderIntegrationError {
  validateModules(recipe: Recipe): string[] {
    const errors = [];
    
    // Check required functions
    if (!recipe.world.scene.includes('scene_intersect')) {
      errors.push("Scene module missing scene_intersect");
    }
    
    if (!recipe.world.lighting.includes('lighting_sample')) {
      errors.push("Lighting module missing lighting_sample");
    }
    
    // Check material counts match
    const sceneMatCount = this.extractConstant(recipe.world.scene, 'NUM_MATERIALS');
    const lightingExpects = this.extractConstant(recipe.world.lighting, 'NUM_MATERIALS');
    if (sceneMatCount !== lightingExpects) {
      errors.push("Material count mismatch between Scene and Lighting");
    }
    
    return errors;
  }
}
```

## Performance Considerations

### Inlining
Small functions may be inlined by the GPU compiler, but we can hint:
```glsl
// Force inline for hot paths
#define INLINE  // GPU compiler decides, but this documents intent

INLINE float dispatch_sdf(Point p) {
  // Critical inner loop function
}
```

### Register Pressure
Material properties struct may be large:
```glsl
// Option 1: Pass full struct (easier but more registers)
Spectrum shade(MaterialProperties props, ...);

// Option 2: Pass only needed values (manual but efficient)
Spectrum shade(vec3 albedo, float roughness, ...);
```
